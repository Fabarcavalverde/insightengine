¿Qué es InsightEngine?

  • Pipeline de minería de datos orientado a objetos desarrollado en Python
  • Automatiza limpieza, EDA, asociación, clasificación, dimensionalidad y regularización
  • Configurable mediante YAML — adaptable a cualquier dataset sin modificar el código
  • Genera este reporte HTML desde los resultados del pipeline

Hallazgos principales

  • Asociación: el 96.3% de clientes son trabajadores extranjeros — segmento dominante y confiable
  • Clasificación: AdaBoost alcanza 78% de precisión global; NaiveBayes detecta mejor el riesgo malo (73.6%)
  • Dimensionalidad: los tres métodos (ACP, t-SNE, UMAP) identificaron 3 clusters coherentes
  • Regularización: R²=0.52 — las variables categóricas explican el 52% de la varianza del monto de crédito
